# Decisif Shelf 1.0.1

[English](README.md) · **简体中文**

一个通过口令解锁、托管在 GitHub Pages 上的极简文件空间。网站代码保存在本仓库，上传的资料保存在另一个独立私有 GitHub 仓库。

[打开 Shelf](https://studio-decisif.github.io/decisif-shelf/)

## 1.0.1 更新

- 文件按上传入库时间倒序排列，最新文件在最上面。大小显示使用十进制 KB / MB / GB。
- 点击或轻点文件整行即可选中，再点击下载箭头。鼠标可以双击下载；触摸双击不下载。上传、下载和主题图标保持视觉尺寸，扩大透明触摸区域。
- 刷新恢复登录时，临时网络失败不再清除会话与缓存列表。凭据失效、加密配置变更或会话损坏仍可能要求重新解锁。
- 底部小字与表头使用相同现代字体，逐字出现加快。上传、按钮可用状态、焦点框和弹窗入场退出采用平滑过渡。上传时原有文件保持正常颜色。
- 登录成功勾停留 300 毫秒。外框圆角与输入框、Confirm 控件对齐。密码框在原位从模糊变清晰，不再位移或缩放。背景真正改变模糊半径，电脑最大约 6px、窄屏约 4px。
- 主题切换增加悬停与按压反馈，配色渐变。系统主题未知或无法读取时默认深色。深色密码框不使用阴影或光晕。
- 手机布局限制页面横向滚动，保留上下滚动和双指缩放。

## 本地运行

需要 Node.js 22 或更新版本。在项目目录执行：

```sh
npm run preview
```

打开 http://127.0.0.1:8765/ ，预览进程需要保持运行。这个地址仅用于本机；分享给朋友应使用 Pages 地址。运行 `npm test` 执行自动化检查。

## 使用

点击 **key**，输入口令并点击 **Confirm**。本地解密成功后立即画勾，不等待 GitHub 数据全部返回。欢迎文字为 `decisif shelf`，当前一轮会完整结束再关闭；每次主动登录只播放一次欢迎音。

点击 **+** 选择文件。新文件行渐显并显示旋转圆环；GitHub 确认提交后显示小绿勾并播放成功提示音。选中文件行后点击下载箭头，只有下载时才获取文件正文。Office 文件下载后用电脑上的对应软件打开。**Created** 是通过 Shelf 上传入库的时间，不是文件原始创建时间。没有时间记录的文件显示 `—`，排在最后。

刷新时恢复会话，先显示缓存文件信息，再检查 GitHub。临时请求失败显示 `error`，不清除登录。点击 **key** 会在原文件列表上打开输入框；点旁边或按 Escape 取消时保留原登录。这个输入框不会修改正式口令。

黑白半圆用于切换主题。首次尽量跟随浏览器或系统；手动选择单独保存，不与登录凭据混用。

## 配置私有资料仓库

创建 fine-grained GitHub Token，只授权**私有资料仓库**，授予 Contents 读写权限。在本地交互终端运行：

```sh
node scripts/setup-vault.mjs
```

接受默认值或填写仓库所有者、名称和分支。随后隐藏输入 Token 与至少 12 位的随机口令。工具检查私有仓库访问后生成 `docs/config/vault.json`，将这个加密配置随网站提交即可。再次运行会替换配置。不要把明文 Token 或口令放进源码仓库，也不要发到聊天中。

仅本地演示时可执行：

```sh
node scripts/setup-vault.mjs --demo
```

这会用口令 `ShelfDemo123` 的内存演示替换真实配置。演示文件刷新后消失。只有明确需要覆盖当前配置时才执行。

## 存储与安全机制

- 网站位于 `STUDIO-decisif/decisif-shelf` 的 `docs/`，Pages 来源为 `main` → `/docs`。
- 资料位于独立私有仓库 `decisif-shelf-storage` 的 `storage/<文件名>`；`.shelf/files.json` 记录入库时间。每批文件与元数据一次提交，非强制更新分支，并处理提交冲突重试。
- 限制为每文件 25 MiB（26,214,400 字节）、每批 200 个文件、每批 100 MiB。这些是按字节计算的限制，列表使用十进制显示。文件平铺存放，不覆盖同名文件。
- 加密采用 PBKDF2-HMAC-SHA256、600,000 次迭代、AES-256-GCM，随机 16 字节盐值、12 字节 IV、128 位认证标签，并认证配置参数。
- 不持久保存口令或派生密钥。为支持刷新恢复，解密后的 Token、配置标识和目录信息暂存在 `sessionStorage`；应用不缓存文件正文。只有主题偏好使用 `localStorage`。
- 正常关闭标签页或浏览器通常结束会话；浏览器恢复标签页或上次会话时可能保留。网页无法保证电脑零痕迹，也无法保证恢复浏览器后一定退出。
- 这是一套面向可信用户的共享口令方案，不是独立用户账号系统。知道口令的人可提取 Token 并使用其完整权限，包括绕过网页调用删除 API。撤销访问需撤销旧 Token 并替换加密配置。公开密文允许离线猜测，请使用随机口令。资料保存在私有仓库，但没有端到端加密。
- 中断的上传可能留下未引用的 Git 对象。网络结果不确定时，先检查列表再重试。

## 验证

自动化检查覆盖二进制请求、加密互操作与篡改、冲突与失败提交、含临时网络失败的连续刷新、触摸与鼠标区别、排序、主题回退、动画时序和 WAV 有效声音。用户已确认真实私有仓库上传成功。浏览器检查过布局宽度、主题、悬停、取消和模糊效果；实际动画观感、出声和性能仍取决于使用设备。
